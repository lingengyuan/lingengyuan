## Hugh Lin · 林耿塬

> Building practical AI tools, local LLM experiments, and small developer utilities.

Software engineer interested in **AI developer tooling**, **agent skills**, and **local-first AI on Apple Silicon**. I like turning recurring workflow friction into tools, then testing the ideas on real hardware instead of stopping at demos.

Most of my public work is around Go/Python tooling, local LLM training and inference, reproducible experiments, and agent workflows.

---

### 🚀 Featured projects

**[skillctl](https://github.com/lingengyuan/skillctl)** — Cross-platform Go CLI for discovering, checking, diagnosing, and safely updating AI skills. Supports multiple skill roots and update providers while protecting local modifications and ambiguous installs.

**[my-skills](https://github.com/lingengyuan/my-skills)** — Reusable Claude/Codex skill engineering workspace covering Obsidian workflows, WeChat archiving/publishing, Git automation, documentation maintenance, and local tooling.

**[gpt2-from-scratch](https://github.com/lingengyuan/gpt2-from-scratch)** — Rebuilt GPT-2 Small (124M) end-to-end on a MacBook Air M5, including pre-training, LoRA, evaluation, MLX migration, optimizer comparisons, and KV-cache quantization. No cloud GPUs.

**[qjl-mlx](https://github.com/lingengyuan/qjl-mlx)** — MLX / Apple Silicon implementation of QJL and TurboQuant, parity-checked against the PyTorch reference and integrated into real LLM inference experiments.

**[minimind-autoresearch](https://github.com/lingengyuan/minimind-autoresearch)** — Automated training experiments on a 26M Chinese LLM using a MacBook Air M5, covering hyperparameter search, pre-training, SFT, DPO, and evaluation.
